📖 คู่มือการใช้งานระบบสืบค้นศัพท์สัตวแพทย์มาตรฐาน v7.0

ยินดีต้อนรับสู่ KAHIS Terminology System — ระบบฐานข้อมูลและสืบค้นรหัสมาตรฐานสัตวแพทย์สำหรับระบบเวชระเบียนอิเล็กทรอนิกส์ (EHR/EMR) โรงพยาบาลสัตว์ มหาวิทยาลัยเกษตรศาสตร์ (ประเทศไทย)

📌 1. บทนำและแหล่งข้อมูลมาตรฐาน 4 แหล่ง (Introduction & 4 Data Sources)

ระบบ KAHIS Terminology เชื่อมโยงรหัสมาตรฐานสัตวแพทย์และคำศัพท์สากลจาก 4 แหล่งอ้างอิงล่าสุด:

  1. SA-PDT 20260930 (Small Animal Problems and Diagnoses Terms): มาตรฐานคำศัพท์สัตวแพทย์อ้างอิงจาก Virginia-Maryland College of Veterinary Medicine (VTSL)
  2. VSCT 20260930 (Veterinary Extension to SNOMED CT): ส่วนขยายคำศัพท์สัตวแพทย์สากล
  3. SCT International 20261101 (SNOMED CT International Core): มาตรฐานคำศัพท์การแพทย์สากลระดับโลก (574,677+ Terms)
  4. KU Custom Synonyms 20261106: คลังคำพ้องและคำแปลภาษาไทยที่รับรองโดยคณะสัตวแพทยศาสตร์ ม.เกษตรศาสตร์

💡 2. หลักการทำงานและสัญลักษณ์มาตรฐาน (Principles & Symbols)

2.1 สัญลักษณ์ประเภทมโนทัศน์ (Concept Status)

  • ≡ Fully Defined Concept (มโนทัศน์ที่นิยามครบถ้วน): มีคุณลักษณะทางคลินิกครบถ้วนสมบูรณ์ตามตรรกะคอมพิวเตอร์
  • ○ Primitive Concept (มโนทัศน์พื้นฐาน): มโนทัศน์พื้นฐานที่ยังไม่มีคุณลักษณะครบทุกมิติ (แสดงเป็นวงแหวนกลมคมชัด เช่น Diarrhea - 62315008)

2.2 ระบบสีป้ายกำกับมาตรฐาน (Unified Badges)

🔍 3. วิธีการใช้งานระบบสืบค้น (User Guide)

3.1 การโหลดฐานข้อมูล (.db และ .db.gz)

ปุ่ม `📂 โหลดไฟล์ DB จากเครื่อง (.db / .gz)` ที่มุมขวาบน รองรับไฟล์ทั้ง 2 แบบ:

  • ไฟล์บีบอัด .db.gz (~53.6 MB): ขนาดเล็ก โหลดเร็ว ประหยัดพื้นที่จัดเก็บ เบราว์เซอร์จะคลายการบีบอัดอัตโนมัติใน RAM ในเวลาเพียง 1 วินาที
  • ไฟล์ก้อนเต็ม .db (~206.6 MB): ไฟล์ SQLite แบบไม่บีบอัดเดิม

3.2 การป้อนคำค้นหาและเงื่อนไข (Search Options)

  • ค้นหาได้ทั้ง 4 รูปแบบ: ภาษาไทย (ท้องเสีย), ภาษาอังกฤษ (Diarrhea), คำย่อ (FLUTD), หรือรหัส Concept ID (62315008)
  • Search mode: Prefix any order (คำขึ้นต้น), Exact match (ตรงตัวเป๊ะ), Partial match (ส่วนหนึ่งของคำ)
  • Description type: All, FSN only (ชื่อทางการ), Synonyms only (คำพ้อง)
  • Language Refsets: All languages, English, Thai (KU Synonyms)
  • Group by concept: รวม 1 มโนทัศน์ต่อแถว หรือแตกทุกแถวตาม Synonyms
  • 🌐 ค้นหาขยายสากล: ขยายการค้นหาทะลุผ่าน SNOMED CT International เต็ม 574,677+ คำ

⭐ 4. ระบบ Favorites (บันทึกคำศัพท์ที่ใช้บ่อย)

  • ปุ่มรูปดาว ☆ / ★: อยู่มุมขวาบนของกล่องสีฟ้า คลิกเพื่อบันทึกมโนทัศน์ที่ใช้บ่อย (ดาวจะเปลี่ยนเป็นสีทอง ★ พร้อมแจ้งเตือน Toast)
  • แท็บ ⭐ Favorites ฝั่งซ้าย: สลับดูรายการที่บันทึกไว้ คลิกเปิดดูรายละเอียดได้ทันที และมีปุ่ม ✕ สำหรับลบรายการ

💡 5. การเสนอคำพ้องภาษาไทย (Suggest Thai Synonym)
